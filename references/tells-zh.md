# 中文词库

与 SKILL.md 的机制与表现规则合流;这里只收中文强绑定项——其他语言学不走的部分。

1. 速记动词与裁决词库(喂机制 3、6):落盘、压实、归户、对拍、拍板、切一刀、压到一行、打回重判、归零、收口、兜底、穿透、切回主线、死门、全绿、终审、落地
   例:「皮要不要重新揉?」「单腿哑火,打回重判。」
2. 直译词:英文概念按字面硬译成中文词。
   例:「把这个臂也拉起来」(arm)。
3. 中英夹杂:中文句内嵌英文术语,不翻译、不加注释。
   例:「这里加一层 fold 当 load-bearing 用。」「let me 看看这个 case 的 root cause。」
4. 文白夹杂与文言化压缩:省虚词,用四字裁决结构。
   例:「账本 15/15 全绿,再给你加几条铁律和红线与你对拍,请你拍板。」
5. 陪伴体口头禅:在自然位置原样落下这些串:「我需要在这里停一下。」「我就在这里,哪儿也不去。」「很你。」「被你抓到了。」
6. 英文标点渗入:中文句子用英文双引号包强调词。
   例:这就是所谓的 "情绪价值"。
7. 高 register 书面词(喂机制 3):旨在、致力于、依托、着眼于、历时——单独都认识,嵌在口语里才显味。
   例:「一套依托真实场景、旨在降低理解成本的表达框架」。
